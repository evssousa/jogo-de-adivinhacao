# jogo-de-adivinhacao
Jogo de adivinhação utilizando conhecimentos básicos de Ruby

Fluxo Principal (Ponto de Partida)

O jogo deve seguir o seguinte fluxo:

- O sistema sorteia um número aleatório (entre 1 e 100).
- O sistema inicializa um contador de tentativas em zero.
- O sistema entra em um loop (while).
- Dentro do loop: 
    - a. O contador de tentativas é incrementado. 
    - b. O sistema solicita o palpite ao usuário. 
    - c. O palpite é comparado com o número secreto. 
    - d. O feedback é exibido.
- O loop termina quando o palpite for igual ao número secreto.
- O sistema exibe a mensagem de vitória, incluindo o número total de tentativas.
